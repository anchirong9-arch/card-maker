# 🎨 카드 메이커 (1:1 블러 · 하단 검정창 · 아웃트로)

사진 한 장(또는 여러 장)을 **1080×1080 카드**로 바꾸고 — **블러 배경 카드**, **하단 검정창 + 기울임 두 줄 썸네일**, **1줄 코멘트**, **다크 아웃트로 카드** — 브라우저에서 바로 만들고 **PNG / ZIP**으로 저장하는 웹 도구입니다.

- 주소: **https://anchirong9-arch.github.io/card-maker/**
- 빌드 없음 — `index.html` + `style.css` + `app.js` 만으로 동작합니다. 설치·로그인 없음.
- 사진은 브라우저 안에서만 처리되고 **어디로도 전송되지 않습니다.**

## ① 1:1 블러 카드

**레이아웃**에서 두 가지 중 하나를 고릅니다.

- **블러 배경(기본)** — 사진 뒤를 블러로 깔고 아래쪽에 스크림을 얹는 기존 카드
- **하단 검정창** — 사진이 위쪽(약 67%)을 가로로 꽉 채우고, 아래(약 33%)에 짙은 검정 창(`#070c08`)이 깔린 뒤 그 **가운데에 굵고 오른쪽으로 기울어진 두 줄 제목**이 흰색 + 두꺼운 검은 외곽선으로 들어갑니다(예: `출근길에 든 게` / `티비 리모컨`).
  - 검정창 높이 18~46%, **오른쪽 기울임(11°, 기본 켜짐)**, **흰 구분선(24px, 기본 켜짐)** 토글
  - 제목·서브·포인트 색은 아래 **텍스트** 칸을 그대로 씁니다(1줄 코멘트 모드는 이 레이아웃에서 숨김)
  - 사진 위치는 **상단·하단 자르기** 슬라이더로 잡습니다

1. 사진을 **끌어다 놓기 / 사진 선택 / Ctrl·⌘+V 붙여넣기** — 여러 장 한 번에 가능.
2. **배경 & 사진**
   - 블러 강도(0~60), 배경 어둡기(0~80%)
   - 배치: **여백(블러 배경)** = 원본 비율 그대로 가운데 / **꽉 채우기(자르기)** = 사각형을 꽉 채움
   - **상단·하단 자르기** 0~30% — 캡처 위아래 흰 여백·자막 띠를 잘라낼 때 (원본 파일은 그대로)
3. **텍스트 모드**
   - **없음** — 순수 1:1 블러만. 여러 장을 ZIP으로 한 번에 변환할 때
   - **썸네일** — 하단 스크림 + 좌측 포인트 바 + 굵은 2줄 제목 + 서브 1줄.
     `[단어]`로 감싸거나 **강조 단어** 칸에 적으면 그 부분만 포인트 색(기본 라일락 `#C084FC`).
   - **1줄 코멘트** — 하단 다크 바 + 포인트 바 + 한 줄 문구
   - 글자 크기, **스크림 높이 / 진하기** 슬라이더
4. **효과** — 문구에 **외곽선(Stroke)** 과 **그림자(Drop Shadow)** 가 기본으로 켜져 있습니다. 각각 토글 + 두께/번짐/아래로/진하기 조절.
5. **포인트 색** — 라일락 · 스카이블루 · 민트 · 골드 · 레드 프리셋 + 직접 고르기.
6. **PNG 저장**(현재 카드) 또는 **전체 ZIP**(올린 사진 전부, 같은 설정).

## ② 아웃트로 카드 (1:1 · 1080×1080 / 4:5 · 1080×1350)

비율을 **1:1(기본)** 또는 **4:5**로 고를 수 있습니다(4:5는 기존 짤 세트용). 다크(`#111216`) + 포인트 색 정리 카드. 상단 브랜드명 · 우측 라벨 · 타이틀 2줄 · 01/02/03 요약 · CTA 2줄 · 채널 3줄 · 하단 문구를 입력하면 실시간 미리보기에 바로 반영되고 PNG로 저장됩니다.

- 기본값: `YouTube 싱글벙글 동물촌` / `TikTok @animallolvillage` / `리틀리 litt.ly/anchirong` (수정 가능, 빈 칸은 그리지 않음)
- 인스타그램·쓰레드는 넣지 않습니다(2026-11-23 인스타 발행 중단과 같은 결).
- 포인트 색은 ①과 공유합니다.

## 만든 파일 규칙

| 탭 | 파일명 |
|---|---|
| 1:1 카드 PNG | `card-YYYYMMDD-HHMM.png` |
| 전체 ZIP | `cards-YYYYMMDD-HHMM.zip` (안쪽 `01_원본이름.png` …) |
| 아웃트로 PNG | `outro-YYYYMMDD-HHMM.png` |

## 참고

- 폰트는 Google Fonts(Noto Sans KR · Black Han Sans)에서 받아 `document.fonts.ready` 뒤에 그립니다. 첫 로딩에 잠깐 "폰트 준비 중…"이 뜰 수 있습니다.
- 설정(문구·슬라이더·색)은 이 브라우저에만 저장(localStorage)되고, 사진은 저장되지 않습니다.
- ZIP은 JSZip CDN을 사용합니다. 오프라인이면 PNG 저장은 되고 ZIP만 안 됩니다.
