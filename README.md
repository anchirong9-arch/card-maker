# 🎨 카드 메이커 (1:1 블러 · 하단 검정창 · 마무리 카드 라일락/동물촌/심플 엔딩 · 심플 세트 3종)

사진 한 장(또는 여러 장)을 **1080×1080 카드**로 바꾸고 — **블러 배경 카드**, **하단 검정창 + 기울임 두 줄 썸네일**, **1줄 코멘트**, **마무리(엔딩) 카드 네 종**(다크 요약 · 라일락 · 동물촌 · 심플 엔딩), 그리고 **심플 세트(인트로 + 화이트 광고 카드 + 심플 엔딩)** — 브라우저에서 바로 만들고 **PNG / ZIP**으로 저장하는 웹 도구입니다.

- 주소: **https://anchirong9-arch.github.io/card-maker/**
- 빌드 없음 — `index.html` + `style.css` + `app.js` 만으로 동작합니다. 설치·로그인 없음.
- 사진은 브라우저 안에서만 처리되고 **어디로도 전송되지 않습니다.**

## ① 1:1 블러 카드

**레이아웃**에서 두 가지 중 하나를 고릅니다.

- **블러 배경(기본)** — 사진 뒤를 블러로 깔고 아래쪽에 스크림을 얹는 기존 카드
- **하단 검정창** — 사진이 위쪽(약 67%)을 가로로 꽉 채우고, 아래(약 33%)는 **진한 검정 → 위로 갈수록 옅어지는 그라데이션**으로 사진과 자연스럽게 이어집니다. 그 문구는 검정 영역 **가운데에 굵고 오른쪽으로 기울어진 두 줄 제목**으로 들어가고, 그림자 없이 흰색 + 두꺼운 검은 외곽선만 씁니다(예: `출근길에 든 게` / `티비 리모컨`).
  - 검정창 높이 18~46%, **위로 부드럽게(그라데이션, 기본 켜짐)**, **오른쪽 기울임(11°, 기본 켜짐)**
  - 그라데이션을 끄면 예전처럼 딱 끊기는 검정창 + **흰 구분선(24px)** 이 나옵니다(그때만 흰 구분선 토글이 보임)
  - 제목·서브·포인트 색은 아래 **텍스트** 칸을 그대로 씁니다(1줄 코멘트 모드는 이 레이아웃에서 숨김)
  - 사진 위치는 **상단·하단 자르기** 슬라이더로 잡습니다

1. 사진을 **끌어다 놓기 / 사진 선택 / Ctrl·⌘+V 붙여넣기** — 여러 장 한 번에 가능.
2. **배경 & 사진**
   - 블러 강도(0~60), 배경 어둡기(0~80%)
   - 배치: **여백(블러 배경)** = 원본 비율 그대로 가운데 / **꽉 채우기(자르기)** = 사각형을 꽉 채움
   - **상단·하단 자르기** 0~30% — 캡처 위아래 흰 여백·자막 띠를 잘라낼 때 (원본 파일은 그대로)
3. **텍스트 모드**
   - **없음** — 순수 1:1 블러만. 여러 장을 ZIP으로 한 번에 변환할 때
   - **썸네일** — 하단 스크림 + 좌측 포인트 바 + 굵은 2줄 제목 + 서브 1줄.
     `[단어]`로 감싸거나 **강조 단어** 칸에 적으면 그 부분만 포인트 색(기본 라일락 `#C084FC`).
   - **1줄 코멘트** — 하단 다크 바 + 포인트 바 + 한 줄 문구
   - 글자 크기, **스크림 높이 / 진하기** 슬라이더
4. **효과** — 문구에 **외곽선(Stroke)** 과 **그림자(Drop Shadow)** 가 기본으로 켜져 있습니다. 각각 토글 + 두께/번짐/아래로/진하기 조절.
5. **포인트 색** — 라일락 · 스카이블루 · 민트 · 골드 · 레드 프리셋 + 직접 고르기.
6. **PNG 저장**(현재 카드) 또는 **전체 ZIP**(올린 사진 전부, 같은 설정).

## ② 마무리(다크·요약) — 1:1 · 1080×1080 / 4:5 · 1080×1350

## ⑤ 심플 엔딩 — 1:1 · 1080×1080

2026-11-25 지시로 **따로 추가한** 완전 심플한 마지막 카드입니다(①~④는 그대로). 사진을 1:1로 꽉 채우고, 아래쪽만 은은하게 어둡게 깐 뒤 **가운데 두 줄 문구**와 **오른쪽 아래 채널 태그**만 얹습니다.

- **사진** — 꽉 채우기(cover). ① 카드와 같이 **상단·하단 자르기**를 쓰고, **사진 흐림(0~24px) · 사진 어둡기**로 사진을 눌러 줄 수 있습니다. 사진이 없으면 `#111216` 어두운 바탕에 문구만으로도 저장됩니다. 여러 장 → **ZIP 일괄 저장**.
- **하단 그라데이션** — 기본 **켜짐**, 높이 38%(20~65) · 진하기 90%. 아래 35~40%를 자연스럽게 검정으로 깔아 글씨를 살립니다.
- **가운데 두 줄 문구** — 1줄(굵은 흰 글씨 52px, 기본 `여러분은 어떻게 생각하시나요?`) + 2줄(작은 흰 글씨 34px, 기본 `댓글로 의견을 남겨주세요!`). 검은 외곽선(기본 3px) · 그림자 토글, **글자 크기 · 아래 여백** 슬라이더. 칸을 비우면 그 줄은 그려지지 않고, 길면 폭에 맞춰 자동으로 작아집니다.
- **채널 태그** — 오른쪽 아래(오른쪽 여백 64px)에 **오른쪽 정렬**로 여러 줄. 기본 `YouTube · 싱글벙글 동물촌` / `TikTok · @animallolvillage` / `리틀리 · litt.ly/anchirong`(textarea에서 자유롭게 수정·삭제, 최대 6줄). 태그 크기(기본 25px) · 문구 위 간격(기본 56px) 조절.
- **PNG 저장** → `ending-simple-YYYYMMDD-HHMM.png`
- 모바일에서는 탭이 **①~④ 2열 2줄 + ⑤ 한 줄 전체**로 배치돼 이름이 잘리지 않습니다.

## ⑥ 심플 세트 (6번째 탭) — 인트로 · 광고 카드 · 아웃트로 3종

2026-11-25 확정한 **심플 버전 3종 세트**를 한 탭에서 만드는 올인원 모드입니다(①~⑤는 그대로). 미리보기 바로 아래 **1. 인트로 / 2. 광고 카드 / 3. 아웃트로** 스위치로 오가며 편집하고, **3종 세트 ZIP**을 누르면 세 장이 한 번에 받아집니다.

- **1. 인트로(썸네일)** — 사진 꽉 채우기 + 하단 검정 그라데이션 + **굵은 흰 제목 1~2줄만**. 좌측 포인트 바·서브 1줄은 없는 `build_outro_simple.py` 의 `01_thumb` 규격(기본 최대 124px, 아래 여백 86px, 검은 외곽선). 그라데이션 높이(52%) · 진하기(100%) · 맨 아래 검정 띠, 글자 크기·최대 크기·아래 여백을 조절합니다.
- **2. 광고 카드(화이트 톤 커뮤니티)** — `downloads/build_card_white.py` 를 브라우저 캔버스로 그대로 옮겼습니다.
  - 흰 바탕 `#FFFFFF` / 연회색 카드 `#F8F9FA` / 테두리 `#E5E7EB` / 진한 글씨 `#111827`
  - 카테고리 알약 뱃지(기본 `집사 · 일상`) · 번호(`035번`) · 글 제목 · 메타(`익명 · 방금 전 · 조회 1,842`)
  - 상품 이미지 첨부(가운데 크롭 / 원본 비율) · 상품명 2줄 · 가격 · 정가·배송 2줄 · 스펙 2줄 · 상품평 줄 · 댓글 2개(작성자·내용, 비우면 그리지 않음)
  - 뱃지·댓글 박스는 `ctx.measureText` 의 실제 잉크 높이(`actualBoundingBoxAscent/Descent`)로 계산해 **위·아래 여백이 같은 정중앙**에 놓입니다(카드 스크립트와 같은 여백 프리셋 3단계).
- **3. 아웃트로(심플 엔딩)** — ⑤와 같은 규격(사진 꽉 채우기 또는 `#111216` + 하단 그라데이션 + 가운데 두 줄 + 오른쪽 아래 채널 태그 3줄).
- **저장** — 현재 단계 `PNG 저장`(`thumb-simple-…` / `card-white-…` / `ending-simple-…`) 또는 **3종 세트 ZIP**(`simple-set-YYYYMMDD-HHMM.zip` 안에 `01_thumb.png` · `02_card_white.png` · `03_outro_simple.png`, 1080×1080 PNG 3장).
- 모바일에서는 탭이 **①~⑥ 2열 3줄**로 배치됩니다.

## 참고

- 폰트는 Google Fonts(Noto Sans KR · Black Han Sans)에서 받아 `document.fonts.ready` 뒤에 그립니다. 첫 로딩에 잠깐 "폰트 준비 중…"이 뜰 수 있습니다.
- 설정(문구·슬라이더·색)은 이 브라우저에만 저장(localStorage)되고, 사진은 저장되지 않습니다.
- ZIP은 JSZip CDN을 사용합니다. 오프라인이면 PNG 저장은 되고 ZIP만 안 됩니다.
